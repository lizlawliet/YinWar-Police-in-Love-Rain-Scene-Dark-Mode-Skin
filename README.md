Proceed as follows:

1. Create the Mobile Work skin and give it a unique name. Insert the CSS code and expand "Advanced." There, check the "Parent Only" box and select "only screen and (max-width: 42em)" under "Media." Save the skin.

2. Create the Main Work skin and select "Add parent skin" under "Parent Skin," where you can choose your Mobile Work skin. Save the skin.

3. Done. You can now click "Use" on the Main Work skin.
